週間進捗報告8/2 再提出動画チェックリスト

目的:
一本の動画で「移動・収集・ゴール・クリア後の遷移」というゲームのコアループを客観的に証明する。

録画前:
[ ] Development版を起動する
[ ] 通常プレイ用の設定にする
[ ] ゴール判定とクリア表示が有効になっていることを確認する
[ ] 画面下部に目的と Bubbles: 0 / 合計数 が表示されることを確認する

一本の動画に必ず収める順番:
1. ステージ選択からゲームを開始する
2. 画面の操作方法と「泡を集めて星のゴールへ向かう」という目的を映す
3. プレイヤーを移動・ジャンプさせる
4. 泡を回収し、Bubbles の数値が増える場面を映す
5. 一度ステージから落下し、同じステージへ正常復帰する場面を映す
6. 星のゴールへ到達する
7. STAGE CLEAR! の表示を最低2秒映す
8. SPACE または Xbox A を押し、ステージ選択へ戻るところまで映す

撮影上の注意:
- 途中で映像を切らず、開始からクリア後の遷移まで一本で撮る
- 今週の成果と関係しないエフェクト紹介やエディタ操作は入れない
- ゴール到達前後と回収数が読める画質にする
- 動画を見直し、上記8項目がすべて視認できることを確認する
