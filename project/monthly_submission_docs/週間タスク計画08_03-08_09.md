# 週間タスク計画 08/03〜08/09

作成日：2026年8月1日  
対象ゲーム：自作エンジンを使用した3D足場・収集アクションゲーム  
今週の目標：ステージ開始からアイテム収集、落下復帰、星への到達、クリアまでのコアループを一本の動画で実証できる状態にする。

## 完了の共通条件

- Development構成で起動し、途中でクラッシュしない。
- 実装した機能を実際のゲーム画面で操作できる。
- 各タスクの完了条件を動画から客観的に確認できる。
- 動画で確認できない機能は、実装済みでも今週の完了にはしない。

## 実施順序

1. W01 ゴール・クリア遷移
2. W02 落下復帰
3. W03 収集と条件表示
4. W04 通しプレイ
5. W05 カメラ
6. W06 コントローラー
7. W07 GPUパーティクルによるフィードバック
8. 余力がある場合のみW08 技術展示
9. W09 提出動画
10. W10 振り返り

## スコープ調整ルール

- 時間が不足した場合、W08から削る。Mustタスクは削らない。
- 新しい機能を思いついても、コアループに直接必要でなければ「今後のバックログ」へ移す。
- 不具合が発生した場合、再現手順、期待結果、実際の結果を記録してから修正する。
- タスクを完了にする前に、完了条件と動画での確認方法の両方を満たす。

## 今後のバックログ

| 優先度 | 項目 | 目的 |
|---|---|---|
| 高 | 複数ステージの難易度調整 | 足場の間隔、落下頻度、収集物の配置を調整して遊びやすくする |
| 高 | 中継地点の視覚表現 | 到達済みの中継地点を色やエフェクトで分かりやすくする |
| 高 | ゴール条件の案内 | 必要な収集数と星へ向かうタイミングを迷わないようにする |
| 中 | 取得・着地・落下時の効果音 | 操作と結果に対するフィードバックを強化する |
| 中 | 天候ごとの視認性調整 | 雨、雪、嵐でも足場とプレイヤーを見失わないようにする |
| 中 | カメラ障害物回避 | 壁や地形がプレイヤーとの間に入った際の見づらさを減らす |
| 中 | ステージ選択画面の進行表示 | クリア済みステージや収集状況を確認できるようにする |
| 低 | 武器・GPUスキニングのゲーム内活用 | 技術展示を操作や演出へ接続する用途を検討する |
| 低 | エフェクト・ポストエフェクトの演出強化 | コアループ完成後に見栄えを改善する |
